# 📖 Návod k použití
Zde je stručný průvodce, jak s aplikací pracovat:

1. Nastavení rozpočtu
Při prvním spuštění (nebo v nastavení) zadejte v záložce **Rozpočet** svůj celkový limit (např. 5000 Kč).

Tato částka se zobrazuje jako váš strop.

Pokud chcete limit  vynulovat, použijte tlačítko pro Reset rozpočtu.

2. Přidávání dárků
V záložce **Přehled** Vyplňte Jméno, Dárek a ceu ->klikněte Přidat Dárek.

Dárek se objeví v hlavním seznamu.

3. Nakupování (Zaškrtnutí dárku)
Zaklikněte ze seznamu ty dárky, které se rozhodnete koupit.
V hlaviččce stránky se vám od rozpočtu odečte částka a zobrazí celkková potenciální útrata.

5. Mazání
Pokud si dárek rozmyslíte, můžete konkrétní dárek smazat - podržením prstu na dárku se objeví možnost smazání.
